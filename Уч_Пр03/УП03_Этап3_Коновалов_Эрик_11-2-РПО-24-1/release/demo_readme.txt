
VetCare v2.1.0 - Демо-версия


БЫСТРЫЙ СТАРТ:
1. Убедитесь, что Docker установлен и запущен
2. Запустите scripts\deploy.bat
3. Откройте http://127.0.0.1:5000
4. Войдите: admin / admin123

ДОКУМЕНТАЦИЯ:
- DEPLOYMENT.md — полное руководство по развертыванию
- DEMO_GUIDE.md — сценарии демонстрации
- RELEASE_NOTES.md — что нового в этой версии

ТРЕБОВАНИЯ:
- Windows 10/11, macOS или Linux
- Docker 20.10+
- Docker Compose 2.0+
- Свободный порт 5000

ПОДДЕРЖКА:
При проблемах смотрите DEPLOYMENT.md раздел "Troubleshooting"

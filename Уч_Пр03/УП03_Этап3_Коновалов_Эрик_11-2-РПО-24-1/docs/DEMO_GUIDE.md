# 📖 DEMO_GUIDE.md — Как быстро проверить VetCare

## 🚀 Быстрый старт

### 1. Запуск проекта
```bash
# Windows
scripts\deploy.bat

# Или вручную
docker compose -f docker-compose.prod.yml up --build -d
```

### 2. Открыть в браузере
```
http://127.0.0.1:5000
```

## 🔐 Тестовые аккаунты

### Администратор
- **Логин:** `admin`
- **Пароль:** `admin123`
- **Возможности:** все функции системы

### Врач (создаётся через админа)
После входа под админом:
1. Перейти на `/register`
2. Создать пользователя с ролью "Врач"

## ✅ Основной сценарий проверки

### Шаг 1: Вход в систему
- Открыть http://127.0.0.1:5000
- Войти: `admin` / `admin123`
- **Ожидаемый результат:** главная страница со статистикой

### Шаг 2: Создание клиента
1. Нажать "Клиенты" в меню
2. Нажать "+ Новый клиент"
3. Заполнить: ФИО = "Иванов Иван Иванович", Телефон = "+79991234567"
4. Нажать "Сохранить"
- **Ожидаемый результат:** клиент добавлен в список

### Шаг 3: Добавление питомца
1. В списке клиентов нажать "Питомцы" для Иванова
2. Нажать "+ Добавить питомца"
3. Заполнить: Кличка = "Барсик", Вид = "Кошка", Порода = "Британская"
4. Нажать "Сохранить"
- **Ожидаемый результат:** питомец добавлен в карточку клиента

### Шаг 4: Запись на приём
1. Нажать "Приёмы" в меню
2. Нажать "+ Новая запись"
3. Выбрать питомца (Барсик)
4. Выбрать врача (admin)
5. Выбрать дату и время
6. Нажать "Создать запись"
- **Ожидаемый результат:** запись появилась в календаре

### Шаг 5: Завершение приёма
1. В календаре нажать "Завершить" для созданной записи
2. Подтвердить действие
- **Ожидаемый результат:** статус изменился на "Завершён"

## 🎯 Критерии успешной проверки

- ✅ Приложение открывается по http://127.0.0.1:5000
- ✅ Авторизация работает (admin/admin123)
- ✅ Можно создать клиента
- ✅ Можно добавить питомца
- ✅ Можно создать запись на приём
- ✅ Можно завершить приём
- ✅ В логах нет критических ошибок

## 📊 Проверка логов

```bash
# Просмотр последних 50 строк логов
docker compose -f docker-compose.prod.yml logs --tail=50

# Логи в реальном времени
docker compose -f docker-compose.prod.yml logs -f
```

**Должно быть:** нет ошибок 500, нет Traceback, все запросы 200/302.

## 🔄 Перезапуск

```bash
# Остановка
docker compose -f docker-compose.prod.yml down

# Запуск
docker compose -f docker-compose.prod.yml up -d
```

После перезапуска приложение должно быть доступно по тому же адресу.

## 🆘 Если что-то не работает

1. Проверьте статус контейнеров:
   ```bash
   docker compose -f docker-compose.prod.yml ps
   ```
   Должно быть: `Up (healthy)`

2. Посмотрите логи:
   ```bash
   docker compose -f docker-compose.prod.yml logs --tail=100
   ```

3. Перезапустите:
   ```bash
   scripts\restart.bat
   ```

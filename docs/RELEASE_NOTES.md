## Что изменилось

### Исправления
- **Кастомная 404-страница:** При переходе на несуществующий URL теперь показывается понятная страница с кнопкой "На главную" вместо технической ошибки Werkzeug.

### Инфраструктура
- **GitHub Actions CI:** Автоматическая проверка кода при каждом push и pull request (линтер, тесты, компиляция).
- **Скрипты поддержки:** Добавлены удобные BAT-файлы для тестирования, сборки и создания релиза.

### Исправления в тестах
- Устранена ошибка `fixture 'self' not found` в smoke-тестах.
- Исправлен дубликат создания пользователя admin в API-тестах.

---

## Как проверить

1. Запустите проект:
   ```bash
   python -m app.run
   ```

2. Перейдите на несуществующий URL:
   ```
   http://127.0.0.1:5000/this_page_does_not_exist
   ```

3. **Ожидаемый результат:** Красивая страница с сообщением "Страница не найдена" и кнопкой возврата на главную.

4. Запустите тесты:
   ```bash
   scripts\test.bat
   ```
   Все 17 тестов должны пройти успешно.

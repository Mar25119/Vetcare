# 🔒 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Если вы нашли уязвимость в VetCare, пожалуйста, сообщите о ней:

1. **НЕ создавайте публичный issue** с деталями уязвимости
2. Напишите на email: [ваш email]
3. Опишите:
   - Тип уязвимости
   - Шаги воспроизведения
   - Потенциальное влияние
   - Предложения по исправлению (если есть)

Мы ответим в течение 48 часов.

## Security Checklist

- [x] .env не загружен в Git
- [x] Пароли хешируются (Werkzeug/scrypt)
- [x] Роли пользователей (admin/doctor)
- [x] CSRF-защита (Flask-WTF)
- [x] SQL-инъекции защищены (SQLAlchemy ORM)
- [x] Резервное копирование настроено
- [ ] HTTPS (для production)
- [ ] Rate limiting (для production)
- [ ] Автоматический мониторинг

## Best Practices

- Никогда не коммитьте `.env` с реальными секретами
- Регулярно обновляйте зависимости: `pip-audit`
- Делайте backup БД перед изменениями
- Используйте разные пароли для разных окружений

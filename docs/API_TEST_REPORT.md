# API_TEST_REPORT.md — Отчёт по API-проверкам VetCare

## Инструмент
**curl** (командная строка)

## Тестируемый адрес
http://127.0.0.1:5000

---

## 1. Успешные запросы

### 1.1. GET /login — страница входа

**Команда:**
```bash
curl -v http://127.0.0.1:5000/login
```

**Результат:**
- Код ответа: **200 OK**
- Content-Type: text/html; charset=utf-8
- Тело ответа: HTML-форма входа

**Статус:** ✅ PASSED

---

### 1.2. GET / — редирект без авторизации

**Команда:**
```bash
curl -v http://127.0.0.1:5000/
```

**Результат:**
- Код ответа: **302 FOUND**
- Location: /login
- Корректный редирект на страницу входа

**Статус:** ✅ PASSED

---

### 1.3. POST /login — успешная авторизация

**Команда:**
```bash
curl -v -X POST http://127.0.0.1:5000/login -d "username=admin&password=admin123" -c cookies.txt
```

**Результат:**
- Код ответа: **302 FOUND**
- Location: /
- Установлена сессионная cookie

**Статус:** ✅ PASSED

---

### 1.4. GET /clients — список клиентов (с авторизацией)

**Команда:**
```bash
curl -v http://127.0.0.1:5000/clients -b cookies.txt
```

**Результат:**
- Код ответа: **200 OK**
- Content-Type: text/html
- Тело ответа: HTML-таблица клиентов

**Статус:** ✅ PASSED

---

## 2. Ошибочные сценарии

### 2.1. POST /login — неверный пароль

**Команда:**
```bash
curl -v -X POST http://127.0.0.1:5000/login -d "username=admin&password=wrong"
```

**Результат:**
- Код ответа: **200 OK** (остаётся на странице входа)
- В HTML присутствует flash-сообщение: "Неверное имя или пароль"

**Статус:** ✅ PASSED (ошибка корректно обработана)

---

### 2.2. GET /clients — без авторизации

**Команда:**
```bash
curl -v http://127.0.0.1:5000/clients
```

**Результат:**
- Код ответа: **302 FOUND**
- Location: /login
- Редирект на страницу входа (Flask-Login)

**Статус:** ✅ PASSED (защита маршрута работает)

---

### 2.3. GET /несуществующий_URL

**Команда:**
```bash
curl -v http://127.0.0.1:5000/nonexistent_page
```

**Результат:**
- Код ответа: **404 NOT FOUND**
- Стандартная страница Werkzeug (см. BUG-02 в DEFECT_LOG.md)

**Статус:** ⚠️ PASSED с замечаниями (требуется кастомная 404-страница)

---

### 2.4. POST /add_client — пустое имя

**Команда:**
```bash
curl -v -X POST http://127.0.0.1:5000/add_client -d "name=&phone=+79990000000" -b cookies.txt
```

**Результат:**
- Код ответа: **200 OK** (остаётся на форме)
- Flash-сообщение об ошибке валидации

**Статус:** PASSED

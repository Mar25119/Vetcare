## ⚠️ Известные ограничения

1. **База данных:** используется SQLite (подходит для демо, для production рекомендуется PostgreSQL)
2. **Email/SMS:** реализована эмуляция через логирование
3. **HTTPS:** не настроен (для production требуется Nginx + SSL-сертификат)
4. **Масштабирование:** один контейнер (для production — несколько workers + load balancer)
